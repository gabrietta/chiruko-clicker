# ちる子満足計画：現在の台詞一覧

現在のゲームでは、画面中央の台詞が一定時間ごとに候補から切り替わります。時間帯・クリック数・毎秒生産量・所持設備・発動中の奇跡・選択中のスキンによって候補が増えます。

## 通常台詞（12）

1. 今日の小さな満足に、感謝いたしましょう。
2. ごきげんよう。本日もほどほどに満たされてまいりましょう。
3. 満足は逃げませんわ。たぶん。ですので、焦らずどうぞ。
4. 教義は簡単ですの。嬉しかったら、それが満足ですわ。
5. 数字が増える様子は、いつ見てもよいものですわね。
6. わたくしを眺める時間も、立派な活動記録ですのよ。
7. 今日も世界のすみっこから、静かに布教中ですわ。
8. 難しいことは明日のわたくしに任せましょう。
9. 休憩もまた満足。異論は認めますけれど、聞き流しますわ。
10. 満たされておりますか？ まだなら、もうひとさわりどうぞ。
11. 大丈夫ですわ。だいたいのことは、おやつと睡眠で整います。
12. その熱意、救済印を押して差し上げたいくらいですわ。

## 条件を満たした時だけ追加される台詞

- クリック20回以上：熱心ですこと。おでこは丁重にお願いいたしますわ。
- クリック100回以上：百回も？ その情熱、もはやひとつの教義ですわね。
- クリック1,000回以上：千のひとさわり……おでこが功徳で輝きそうですわ。
- 毎秒生産が1以上：何もしない時間にも、満足は育ちますの。
- 毎秒生産が1,000以上：もう手動より設備の皆さまのほうが働いておりますわね。
- 毎秒生産が1,000,000以上：一秒ごとの満足が、ちょっとした災害の規模ですわ。
- 累計満足が1,000,000,000以上：ここまで来ると、数字というより景色ですわね。
- 奇跡が1つ発動中：発動中の奇跡名が入った「○○が来ております。今のうちですわ！」
- 奇跡が2つ以上重なった時：奇跡が重なっております！ 理屈はあとで考えましょう！
- 奇跡が2つ以上重なった時：コンボ中ですわ。いまは数字だけをご覧なさいませ！

## 購入・再布教などのイベント台詞

画面上の台詞とは別に、次の操作時に音声が呼ばれます。

- 設備購入：お迎え、ありがとうございますわ。
- アップグレード購入：御利益を授けましょう。
- 恒久教義購入：この教義は、次の世界にも残りますわ。
- 再布教：もう一度、世界を満たしましょう。

## 音声化について

できます。おすすめは次の順番です。

1. まず通常台詞2本、設備購入、実績解除の4本だけ生成して音量・声質を確認する。
2. 問題なければ、上の固定台詞をまとめてMP3化する。
3. MP3を `public/assets/audio/voice/` に置き、台詞とファイル名の対応表を設定する。
4. 条件付き台詞や設備台詞を追加し、最後にNetlify用の `dist` を作る。

音声ファイルはブラウザ側で再生するため、ゲーム公開後もAPIキーは不要です。逆に、ElevenLabsのAPIキーをゲーム本体やNetlifyへ入れるのは危険です。生成は手元の「かんたん音声メーカー」またはローカルのTTSスクリプトで行い、完成したMP3だけをゲームへ入れます。

ファイル名は、例えば次のようにすると管理しやすいです。

```text
public/assets/audio/voice/
  dialogue-base-01.mp3
  dialogue-base-02.mp3
  dialogue-morning-01.mp3
  dialogue-facility-sora4-01.mp3
  event-purchase.mp3
  event-upgrade.mp3
  event-achievement.mp3
  event-prestige.mp3
```

MP3を用意してもらえれば、こちらで音声対応表を作り、現在のランダム台詞・設備別台詞・購入/実績/再布教イベントへ割り当てられます。未収録の台詞は、今まで通りブラウザ音声合成へ自動フォールバックできます。

台詞と保存先をまとめたCSVも用意しています：`docs/dialogue-voice-manifest.csv`。付属スクリプトを使える環境では、CSVを読み込んで一括生成できます。

今回の6本だけを生成する場合は、`scripts/generate-six-voices.cmd` をダブルクリックするだけです。付属アプリの場所が同じなら、ボイス選択・タグ強化相当の演出・保存先・ゲームへの対応表更新まで自動で行います。

6本以外もまとめて生成する場合は、`scripts/generate-all-voices.cmd` をダブルクリックします。既に存在するMP3は自動的にスキップし、未生成の固定台詞だけを追加します。条件によって文章が変わる「{buffName}」台詞は、同じ音声を使い回せないため対象外です。

```powershell
npm.cmd run voice:generate -- `
  --tts-script "I:\かんたん音声メーカー-案内付き\win-unpacked\Codexスキル\elevenlabs-tts\scripts\elevenlabs-tts.mjs" `
  --voice "声のIDまたは声名" --v3
```

まず `--dry-run` を付けると、生成せずに対象ファイルだけ確認できます。生成には付属スクリプトが使うElevenLabs APIキーが必要です。キーはチャットへ貼らず、手元の環境変数またはアプリ側の設定だけで管理してください。

なお、現在のボイス再生対象は中央の台詞と、設備購入・強化・教義・再布教の4イベントです。満足通信、救済の欠片の通知、オフライン報酬、異常検知の警告は画面表示のみで、まだ音声は割り当てていません。必要になれば同じ仕組みで追加できます。

アップグレード購入の音声だけは、画面表示を「御利益を授けましょう。」のまま、読み上げ入力を「ごりやくを授けましょう。」へ置き換える設定にしています。
